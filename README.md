# Autumn Hill AC & Heating

Single-page marketing website for Autumn Hill AC & Heating.

## Preview locally

From the repository root:

```sh
python3 -m http.server 4173 --directory dist
```

Then open `http://localhost:4173`.

## Before public launch

Update the preview contact details in `dist/index.html`:

- phone number
- email address
- service area

The request form opens the visitor's email app and does not send data to a server.
